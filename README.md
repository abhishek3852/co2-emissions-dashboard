# 🌍 CO₂ Emissions Dashboard

An interactive data visualization project analyzing global CO₂ emissions using Python, Pandas, Plotly, and Streamlit.

## 📊 Project Overview
- 10 analytical questions answered with publication-ready Plotly visualizations
- Interactive Streamlit dashboard deployed on Streamlit Community Cloud
- Dataset: Our World in Data — CO₂ and Greenhouse Gas Emissions

## 🛠️ Tools Used
- Python, Pandas, Plotly, Streamlit
- Jupyter Notebook
- GitHub + Streamlit Community Cloud
